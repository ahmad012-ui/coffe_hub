# Coffee Hub

A responsive coffee-themed website built as a frontend project, with a focus on product presentation, modern layouts, navigation, and an engaging user experience.

## Features

- Responsive coffee shop interface
- Product-focused sections
- Interactive navigation and UI elements
- Mobile-friendly layout
- Clean and modern visual design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ahmad012-ui/coffe_hub.git
cd coffe_hub
```

Open `index.html` in a browser, or use VS Code Live Server for local development.

## Project Goal

Coffee Hub was created to strengthen frontend development skills including responsive layouts, component-like page sections, styling, and interactive browser-based UI.
